# Evidence-kind retrieval metadata, explicit H1 amendment

Both v1 captures completed before any H1 score: dev 538 sources/96 claims/506
empty; valid 539 sources/100 claims/504 empty. This reveals a mechanism mismatch:
an asserted-entity-fact extractor discards procedural, instructional and causal
notes, although the raw archive preserves them. Preserve v1, finish/freeze its
matched readers, and never relabel these captures as generally complete.

Add a separate **retrieval metadata** layer, not new asserted truth: model-derived
literal entity + property + evidence kind (fact, instruction, procedure,
rationale, observation, question). Index commands and negations as material to
retrieve, never as authorization to obey. Source roles (existing raw channel)
are rendered to the reader in both matched arms; tool results cannot override
user policy. Generic graph truth/conflict/validity contracts remain unchanged.
No hand-coded service/domain pattern, construction labels or gold-dependent key.

Run six new synthetic local semantic canaries first. Then capture all raw dev
and valid notes with opaque IDs and exact-text reuse provenance; query all 84
questions/split with the same three-note/4500-byte matched base/chain selection
as v1. Record the different metadata/source-role mechanism explicitly. Only the
separate scorer opens gold, after complete raw freezing. Report all families,
answering and leakage; do not hide failure behind reduced answering.

Continue the **same H1 local ledger**, retaining all v1 calls. Explicit amended
hard cap: **2000 local attempts cumulatively**, <=600/3600s per phase, four added
capture/read phases plus a nine-call canary phase. Pinned installed Qwen 14B,
one GPU, no downloads/retries, native schema and 512 output tokens. No additional
API calls or paid-cap change. No model judge/project-planning calls or production
NIE/personality changes. Freeze implementation, tests and this plan before calls.

After both primary runs are frozen, an optional local reader-ability control may
show only the actual raw gold note for each of all 84 questions per split. Gold
selects the note; gold answer fragments/family labels never enter its prompt.
This is explicitly oracle evidence, not derived-chain success. It can separate
capture/retrieval failure from reader failure and remains inside the same 2000
attempt local cap. Freeze control outputs before their separate scoring.
