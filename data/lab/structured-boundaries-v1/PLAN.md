# Structured boundaries v1 — preregistered engineering repair

Date: 2026-11-05. Exploratory/model-free engineering checks, not independent semantic confirmation. Follows the preserved integrity audit at `5eeb8cc` and community issues #106 (cache), #107 (time/scope) and #108 (stale reader).

## Hypotheses and rejection

1. Exact whole-source-text reuse of a prior model interpretation, restricted to the same scope/source policy and available recording time, prevents the reproduced learned-shell conditional/coordination failures. Disagreement between prior interpretations rejects reuse. Literal text equality is not semantic verification of the original model proposal; old accepted claims are not retroactively repaired.
2. Source-provenance-indexed relation shells plus scope/time-visible plan validation make model-visible query packets and semantic results invariant to unavailable/private source appends. Any byte difference in the packet or semantic result rejects this boundary. No constant-time or caller-authentication claim.

New versions only. Frozen v1/v2, path v5, scorers, raw logs, kernels and NIE remain unchanged. A candidate cache miss delegates extraction to a caller/model; it never fabricates a claim or silently writes. Exact-only reuse may sharply reduce cache coverage. Compare that opportunity/cost on already-captured development sources without generating replacements. Do not call this an end-to-end answer improvement.

## Before execution

- Unit/adversarial checks: conditional/compound/negated/quoted/Unicode text, positive exact replay, scope/policy/time mismatches, inconsistent prior interpretation, reopen/persistence, and rejected derivation without a log append.
- Metamorphic matrix: independent synthetic entity/relation/value substitutions, query times and source orders; compare packets and outputs before/after future/private appends, including unique canary shells and predicate probes. Run in temporary directories with no models/gold.
- Record all failures and denominators. Primary engineering threshold: zero violated declared invariants, with functioning positive controls. Cache opportunity loss is descriptive and never hidden by rejecting all inputs.
- Run focused regressions, memory/claim gates and the appropriate full software suite after new code stabilizes. Global packages stay unchanged.

No new API/model call is part of this phase. The existing Flash ledger remains frozen at 463 attempts / $1.852 reserved of $2. A reader experiment is a separate bounded protocol; public issue #108 is not permission to exceed that cap. No sealed H1/LifeSim inputs, new benchmark downloads or production changes.

## What follows a decision

Record whether the boundary repair is accepted as engineering behavior and its explicit limits. Then execute one separately frozen whole-family reader/conflict diagnostic, rather than add unrelated unexecuted designs. Keep at most two pending experiments per track. Community responses can propose counterexamples; they do not count as independent review until actual review evidence exists.
