# Local iterative retrieval follow-up to the failed hard external diagnostic

The completed v1 benchmark produced 0/100 exact answers for ordinary K on both readers, 4/100 for Flash B, and 1/100 for local B. These negative results and their original caps remain unchanged. Inspection after the raw freeze/gold join shows that first-step records can be retrieved while the next relation's entity is absent from the query; one-shot lexical retrieval cannot follow that chain. This is a **post-hoc engineering repair on spent public development questions**, not a new held-out result or a comparison with memory companies.

Before new calls, freeze a separate local-only runner. Use the same complete 100-question 262k variant, same raw archive, same initial B packet and **same 4500-byte evidence ceiling**. Do not parse gold, add supplied slots/chains/current labels, extract a hand-tuned relation grammar or correct final answers. The local reader may emit either a final value or UNKNOWN with up to two next search queries. Search the same raw archive with the frozen kernel's unlocked BM25; retain new evidence before old evidence within the fixed budget, and display retained records in source order. At most six stateless read/search rounds per question. Never put a model-invented intermediate fact into the archive.

Local Qwen 14B only, same pinned weights, temperature 0, context 4096, up to 256 generated tokens for a JSON object containing `value` and `queries`. The generic output schema constrains syntax, never answer values. The three positive controls reuse the already validated prior control messages. Zero paid calls and no change/reset to the Flash ledger. This separate repair phase is bounded by **603 local calls / 1200 seconds**, including three controls. Unload its owned model after the phase. No automatic retry or partial-run mixing.

Primary endpoint remains normalized exact match over all 100 questions. Commit raw hashes before another score join. Record final emitted answers as-is, UNKNOWN, invalid JSON, search queries, evidence IDs and round counts. Compare descriptively to the local B baseline; the new query-output schema and search loop are both changed, so this does not isolate a single causal component. Reusing the public questions after diagnosis means a higher score cannot establish transfer, independence or generalisation. The readiness target is not lowered; failure stays a failure. A useful positive result would still need a separately frozen transfer on another corpus before promotion.
