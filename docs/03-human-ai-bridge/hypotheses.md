# Falsifiable Hypotheses

Status: outline

## H1 — Complementary stores

A separate exact episodic store plus evidence-linked semantic/procedural memory will improve long-horizon task performance over a single flat memory store at equal context-token cost.

Reject if the dual system does not improve downstream performance or integrity across multiple task families after controlling for retrieval budget.

## H2 — Causal future utility

A retention model trained on counterfactual downstream benefit will make fewer critical retention errors than one trained on retrieval frequency or benchmark evidence labels alone.

Reject if causal labels provide no reliable out-of-distribution improvement relative to their collection cost.

## H3 — Operational salience

Outcome severity, rollback cost, calibrated prediction error, and strategy change will improve retention and retrieval beyond relevance, recency, and access frequency.

Reject if gains disappear on held-out tasks or primarily retain noisy failure traces.

## H4 — Provenance-preserving consolidation

Derived memories that retain links to immutable episodes will reduce unsupported claims and stale-memory errors compared with in-place summary rewriting.

Reject if provenance adds cost without improving correction, audit, or downstream accuracy.

## H5 — Type-conditioned retention

Different retention policies for transient state, stable preference, decision rationale, failure, fact, and procedure will outperform a global decay function.

Reject if a global policy matches performance and calibration under equivalent complexity.

## H6 — Multi-index retrieval

Routing queries across lexical, semantic, temporal, entity, and causal indexes will recover critical memories missed by dense similarity alone.

Reject if hybrid routing does not improve critical recall per retrieved token.

## H7 — Retrieval-trigger policy

A learned or rule-based trigger deciding when to search memory will reduce cost while preserving critical performance relative to searching on every turn.

Reject if misses from skipped retrieval outweigh token and latency savings.
