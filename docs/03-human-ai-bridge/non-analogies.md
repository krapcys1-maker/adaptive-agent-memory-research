# Where the Human-Memory Analogy Breaks

Status: in-progress

- A disk can preserve exact bytes; human episodic recall is reconstructive.
- Digital storage capacity and biological metabolic constraints differ radically.
- A model context window is not equivalent to consciousness or a central executive.
- Embedding similarity is not a direct model of human associative memory.
- A numeric “emotion vector” is not an emotion.
- File deletion, index suppression, and biological forgetting are different operations.
- Model parameters contain learned regularities but are not a user-auditable semantic-memory database.
- Human memories are embedded in perception, embodiment, motivation, and identity; many LLM agents observe only text and tool outputs.
- A human can sometimes know that they forgot something; a system may lack any record that an event was missed at capture time.
- Exact replay of digital events can amplify poisoned or malicious content in ways unlike ordinary biological recall.

Biological terminology is acceptable only when accompanied by an operational definition and an experiment.
