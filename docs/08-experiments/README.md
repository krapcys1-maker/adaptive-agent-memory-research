# Experiment Specifications

No product implementation belongs here yet. This directory stores preregistered experiment designs, baselines, metrics, datasets, and rejection criteria.

Each experiment should include:

```text
question
hypothesis
independent variable
dependent variables
controlled variables
datasets
train/validation/test boundaries
baseline systems
ablation plan
statistical analysis
cost accounting
failure criteria
artifact locations
```

Priority experiment families:

1. Memory subsystem error decomposition.
2. Raw episode versus summary fidelity.
3. Flat versus complementary stores.
4. Semantic versus temporal/causal retrieval.
5. Retrieval frequency versus counterfactual utility labels.
6. Operational-salience ablation.
7. Archive/suppression versus deletion.
