## Method and result

In aversive olfactory conditioning, behaviorally forgotten information persisted in mushroom-body output neurons that did not currently guide avoidance. Recovery required reminder odor plus training context and specific Kenyon-cell output and dopaminergic pathways during reminders. The study used thermogenetic/optogenetic perturbations, calcium imaging, protein-synthesis manipulation, and altered reminder cues. Misleading reminders could produce false learned avoidance depending on original context.

## Limitations

- This is a fly conditioning result, not evidence that inaccessible human or agent memories share its circuits.
- Reminder-dependent behavioral recovery can reconstruct and distort; it is not a lossless file restore.
- Experimental memory expression and a computational record checksum are different observables.
