# Human Memory Research Map

Status: outline

The purpose of this section is not to imitate brain anatomy. It is to identify computational problems that biological memory research has studied deeply.

## Research modules

| Module | Topics | Potential agent-memory relevance |
|---|---|---|
| Working memory | maintenance, manipulation, capacity, attention, interference | context construction and active state |
| Episodic memory | event binding, what-where-when, source, reconstruction | experience storage and evidence retrieval |
| Semantic memory | concepts, facts, schemas, semanticization | consolidated knowledge and beliefs |
| Procedural memory | skills, habits, sequences, automaticity | reusable action policies |
| Encoding | goals, attention, novelty, depth, distinctiveness | write gating and memory representation |
| Consolidation | stabilization, systems transfer, replay, interleaving | background memory processing |
| Reconsolidation | updating after retrieval | versioned correction and revision |
| Forgetting | decay, interference, inhibition, cue failure | archival and retrieval suppression |
| Retrieval | cues, pattern completion, context reinstatement | multi-index search and query expansion |
| Emotion/reward | arousal, valence, reward, prediction error | outcome-conditioned salience |
| Metamemory | confidence, source monitoring, feeling of knowing | knowing when and how to search |
| Prospective memory | delayed intentions and triggers | reminders, unresolved goals, resumable work |

## Core cautions

- Human memory is reconstructive, but an engineered system can and often should preserve exact records.
- “Memory strength” has multiple meanings across theories.
- Failure to recall does not prove that a trace was erased.
- Functional categories do not map one-to-one onto isolated brain regions.
- Findings in word-list experiments may not generalize to months-long agent tasks.
- Emotional salience may enhance selected details while impairing peripheral information.
