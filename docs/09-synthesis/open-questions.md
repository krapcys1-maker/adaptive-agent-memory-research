# Open Questions

- Is future utility stable enough to learn across users, models, and domains?
- How much counterfactual evaluation is affordable?
- Can rare catastrophic memories be retained without overwhelming everyday retrieval?
- What is the safest reversible consolidation operation?
- Should semantic memory represent facts, beliefs, or both as separate types?
- Can procedures be evaluated independently of the model executing them?
- How do we measure memory influence when model reasoning is partially hidden?
- Which benchmark remains meaningful when its full history fits inside a modern context window?
- How should user corrections propagate through summaries, graphs, embeddings, and procedures?
- Can shared multi-agent memory maintain access control and source trust?
