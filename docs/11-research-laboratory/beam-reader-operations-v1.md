# BEAM reader phase: execution and evidence boundaries

This is an owner-specific exploratory research instrument, not a general benchmark SDK. Read the [frozen protocol](../../data/lab/beam-reader-evidence-v1/PLAN.md), [source-window contract](../04-systems/source-windows-v1.md) and latest [handover](../../HANDOVER.md). Do not infer completion from this operations guide. Actual completion, counts and verdicts belong in the phase result.

## Stages and immutable evidence

1. Format-v2 separates full source messages and reader questions from evaluator annotations. It preserves unknown time. Earlier v1partial success and full-data rejection remain unchanged.
2. Source windows preserve original messages, roles, offsets and hashes. Visible-only FTS snapshots bind a scope and available-sequence cutoff. This stage makes no model calls and does not establish semantic retrieval quality.
3. Reader preparation hashes the evaluator file without parsing its values. It fixes the complete605call matrix, native schemas, aliases and exact common B/C evidence. It verifies the retained prior H1/API ledger base, and refuses an existing BEAM ledger or output directory. Commit its public content-free preparation before execution.
4. Local execution uses only the fixed installed Qwen model/digest. Five synthetic controls precede600primary calls; a failed control, cap, timeout, transport error or identity mismatch stops the phase without a hidden retry. Each attempt is retained before network I/O. Only the owned model is unloaded. A failed/partial phase is not resumable by relabelling its output directory.
5. Completion writes a raw-freeze receipt binding all original requests, responses, final answers, task ledger and model-release evidence. Commit the content-free receipt **before** joining references. Do not upload the bound private files.
6. `scripts/reviews/audit_beam_reader_evidence_v1.py` reconstructs all605native requests/responses, the200matched evidence pairs, literal guard decisions and cumulative counters. It never reads references. Run against the frozen private access/reader archives; preserve its exclusive-create receipt.
7. Only then may `scripts/reviews/beam_reader_authored_review_v1.py prepare` read fixed labels. Its committed-raw gate precedes the first semantic reference read. Packet/mapping hashes and committed tool identity are retained. Candidate IDs mask arms; identical valid answer text is deduplicated within a question only. Invalid native output is always a primary failure, even when its fallback is UNKNOWN.
8. The author reviews every candidate against the original rubric. Each verdict records case/candidate IDs, complete-rubric pass, material contradiction and a short final reason. Reference defects/uncertainty stay explicit; no gold edit, automated semantic judge or answer repair. `score` rejects missing/duplicate/extraneous verdicts and changed review code, then reports all200cases, raw/delivered differences, per-history/ability counts and the prespecified screen.

Native request/response logs are private final-content records; no reasoning fields are collected. Hash receipts alone are integrity evidence, not independent semantic confirmation. The official BEAM model judge is not executed, and these authored scores must not be labelled official BEAM accuracy.

## Continuation and reproduction limits

The fixed runner deliberately checks this project's historical H1local3262 and paid463attempt base. A contributor cannot honestly bypass that check by making up ledgers. An independent new run needs a separately recorded protocol/ledger base and versioned successor, preserving this phase and counting its own actual attempts/cost. Do not patch the frozen runner or silently reset counters to obtain another attempt.

Private restoration chains retain the original data/labels, prepared matrices, snapshots and outputs. Public artifacts supply pinned input identities, source/config commits and content-free receipts. A clean checkout does not include the private dataset, model weights, environments or raw generations. Existing tests use synthetic data and do not require model/API access.

N is genuinely memory-off. B is ordinary lexical evidence. C is a **new read-time output contract over B's exact evidence**, not the old graph candidate. Valid literal quotes prove source location; they can still accompany a semantically wrong answer. No screen outcome integrates C into NIE or validates general capture, consolidation, forgetting, competitive superiority or a universal long-term-memory product.
