# Source windows v1: exact text, explicit visibility and bounded messages

Engineering contract, 2026-11-05, issue109. This is a new source access layer, not a modification of frozen kernels, a semantic extractor or proof of memory usefulness.

Keep every full prepared source. Windows retain source identity/hash, origin role, available stream sequence, raw time anchor, and exclusive character/UTF-8 byte offsets. Character offsets count Python Unicode code points, not grapheme clusters. Text is never normalized or repaired. Null/raw time stays unknown; sequence is availability order, not calendar/fact validity. IDs bind all source metadata and the split configuration. Splits prefer nearby whitespace, with a hard code-point-safe cut when necessary. Overlap never creates a gap; reconstruction is tested. A partial window does not establish complete context or entailment.

The fixed initial configuration is1600text bytes and160overlap bytes, chosen before retrieval/model outcomes. Packet budgets include all serialized system/question/evidence headers in the **messages** portion, under both UTF-8 and the frozen native client's ASCII-escaped JSON convention. Whole-request parameters are separate and must be charged by any later model runner. Oversized candidates are omitted with explicit counts, never silently cropped. Original source roles are quoted provenance, not live chat roles or authorization. No expected answer/rubric/family/support annotation enters this layer.

An SQLite snapshot owns one scope and one availability cutoff. Only sources visible at build time enter its source tables and FTS5 statistics; foreign/future sources cannot influence BM25/IDF before filtering. It refuses another view rather than pretending to answer historical queries from a later index. A different cutoff requires another immutable snapshot. Ranking ties use stable window IDs. Query tokens come from the already frozen lexical tokenizer in the runner; this is ordinary lexical retrieval, not a new semantic-search claim.

Snapshots preserve original text, window text/offsets and metadata. They are exclusively created, never overwritten, and opened read-only for retrieval. Selected windows are rechecked against stored original text before rendering. This is an integrity/access contract, not authentication of caller-supplied scope/roles, tamper-proof storage, semantic validation, selective forgetting or the earlier graph candidate.
